# Landing Page Project

Outreach landing page for fitness operations software (shared core + client extensions).

## Commands

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

## Before publishing

1. Update `CONTACT_EMAIL` in `src/content.ts` (replace `hello@example.com`)
2. Update product name `FitCore` in `src/content.ts` and `index.html` when brand is chosen
3. Read `docs/BUSINESS_CONTEXT.md` for product direction

## Cursor

For product or copy work, read `docs/BUSINESS_CONTEXT.md`.

We build outreach for B2B fitness operations — not consumer apps. No fake social proof.
